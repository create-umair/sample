# Shilajit Energy Drinks - redesigned front end

Static site (HTML, CSS, JS). Shop, cart and checkout links point to your live Shopify store.

## Put it online with GitHub Pages
1. Create a repo and upload these files to the root (index.html must be at the top level).
2. Repo Settings > Pages > Deploy from a branch > main, folder / (root).
3. Open the URL GitHub shows (usually https://YOUR-NAME.github.io/REPO/).

Edit text in index.html, colors in style.css (top of file), flavors in script.js.
